# Prototipo funcional — Sistema de gestión para un hotel boutique

Prototipo del Seminario de Sistemas "Análisis y Diseño de un Sistema de Gestión para un Hotel Boutique" (Proceso Unificado, UNSa).

Incluye los circuitos principales: reservas (con pago), check-in (con y sin reserva), check-out (cargos adicionales y factura) y venta de productos. El resto de los módulos se muestra, pero sus acciones no están incluidas. Las integraciones con las OTAs, ARCA y el correo se simulan.

Tecnologías: HTML, CSS y JavaScript, con Bootstrap 5 y Bootstrap Icons. Los datos (ficticios) se guardan en el navegador (localStorage).

Para usarlo localmente basta con abrir `index.html` en un navegador.
